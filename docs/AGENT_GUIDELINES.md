# Agent Guidelines

These instructions apply to AI agents and other contributors working on this project.

## Before editing

- Read the root `AGENTS.md`, [`PROJECT_RULES.md`](PROJECT_RULES.md), and [`../ROADMAP.md`](../ROADMAP.md).
- Read the episode(s) and continuity notes that relate to the requested change.
- Identify the specific requested outcome; do not make unrelated story or repository changes.
- If a major story decision is unspecified, preserve flexibility or document a proposal instead of treating an assumption as established canon.

## While editing

- Make focused, reviewable changes and preserve existing Markdown style and file naming.
- Keep episode prose within the 1,000-word limit defined in `PROJECT_RULES.md`.
- Maintain continuity for character details, motivations, relationships, locations, chronology, and unresolved plot threads.
- Use original prose and avoid copying or closely imitating source material.
- Do not silently rewrite established events, character facts, or the roadmap. Explain proposed changes in the relevant notes or response.
- Do not claim that a draft was tested, reviewed, or completed unless those checks were actually performed.

## After editing

- Check all changed Markdown for clear headings, readable formatting, and working relative links.
- Verify the story body word count for any episode you add or substantially revise; state the count in the episode metadata.
- Check the episode against the project rules and related continuity notes.
- Update the roadmap and reading order when episode titles or statuses change.
- Summarize what changed and note any unresolved decisions or checks that remain.

## Episode status

Use only these statuses: `Planned`, `Draft`, `In review`, and `Complete`. An agent may set an episode to `Complete` only after all applicable checks in `PROJECT_RULES.md` pass. Otherwise, leave it as `Draft` or `In review` and state what remains.
